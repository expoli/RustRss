# 隐私与数据

RustRss 默认把订阅源、文章、阅读状态和应用设置存放在本地 SQLite 数据库中，不要求账号，也不提供云同步。

## AI 请求

只有在用户配置服务商并触发摘要、翻译或连接测试时，相关请求才会发送到所选端点。AI 请求可能包含文章正文、模型设置和提示词。API 密钥存入操作系统凭据库，不进入数据库或普通日志。使用在线服务时，数据处理方式受服务商政策约束。

## MCP 访问

MCP 服务默认关闭。启用 HTTP 后只监听回环地址；读取请求需有效 token。默认只读，写 token 与危险工具开关需要显式配置。agent 获得读取权限后，可以访问同一数据库中的订阅和文章；请只把凭据交给你信任的本机客户端。

## 文章图片和缩略图

feed 正文中的远程图片由 WebView 按文章内容加载。列表缩略图开启时，浏览器会直接连接图片站点，不经过订阅代理；站点可能看到你的 IP 地址和请求时间。可在外观设置中关闭缩略图，关闭后列表缩略图请求停止。

## 日志

应用日志用于故障诊断。日志会对常见 URL 凭据、token 和密钥参数作脱敏；分享日志前仍建议检查其中是否含有你不想公开的信息。日志目录和打开方式见[开发指南](development.md#数据库与诊断)。
