# 功能介绍

## 三栏阅读

- **订阅导航**：查看未读、星标、稍后读、全部文章和订阅源；可将订阅整理到文件夹。
- **文章列表**：按最新、最早或未读优先排序，可隐藏已读并连续加载更多文章。
- **正文阅读**：安全清理 feed HTML，保留文章结构；可以在列表中搜索标题和正文。

条目可以标记已读、星标、稍后读或加标签。设置中的主题、字体、列表密度和摘要行数可按阅读习惯调整。

## 键盘操作

| 按键 | 操作 |
| --- | --- |
| `j` / `k` | 移动到下一篇 / 上一篇 |
| `Enter` | 打开文章 |
| `u` | 切换已读状态 |
| `s` | 切换星标 |
| `l` | 切换稍后读 |
| `t` | 管理标签 |
| `U` | 切换只看未读 |
| `r` | 刷新订阅 |
| `A` | 标记当前视图全部已读 |
| `g` / `G` | 移动到第一篇 / 最后一篇 |
| `/` | 搜索 |
| `Esc` | 清除搜索或关闭弹层 |
| `?` | 查看快捷键帮助 |

在输入框或弹层内时，导航快捷键不会触发。

## 订阅与更新

支持 RSS 2.0、Atom 和 JSON Feed。首页 URL 可自动发现 feed；OPML 用于订阅迁移。自动刷新、启动时刷新、通知和单源刷新间隔可在设置中配置。

RSSHub 地址可配置为自建实例或镜像。可使用 `rsshub://path` 保存与实例无关的订阅地址，之后在设置中切换实际使用的实例。

## 主题与正文

提供浅色和深色主题，以及 Clear、Paper、Slate 外观预设。颜色、字体、列表密度和正文排版可分别调整；修改在预览中确认后保存。

文章缩略图默认可通过外观设置开关。开启时，图片由 WebView 直接从图片站点加载；详情见[隐私与数据](privacy.md#文章图片和缩略图)。
