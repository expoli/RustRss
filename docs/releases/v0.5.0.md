## 本版内容（视觉重设计）

- **「报纸」（Print）成为默认视觉主题**：纸墨配色加一处编辑部红（暗色为夜印暖黑 + 朱红），
  列表标题与阅读正文改用衬线（16.5px/1.85），报头 2px 墨线为全页唯一粗线，选中行改为
  「批注」语义（红竖线 + 红标题，无色块）；新增第四套预设 Print，Clear / Paper / Slate
  保留可选，明暗可分别选择，所有值仍可覆盖。设计流程：oil-ui 方法论四方向小样对比页 →
  用户选定 → 三轮独立视觉评审（7.3 → 8.4/8.2 → 8.6/8.5）。
- 阅读头操作行合并：标签栏并入操作行（桌面受限单行展示、溢出裁切；触屏独立整行保 48px
  触控目标），阅读操作改无框安静语法；红竖线专属「选中」语义。
- 设置对话框布局与交互一致性修正：历史恢复行可见标签、示例明暗切换并入示例卡头、代理区
  表单网格统一、数据面板去重、MCP 轮换 token 降为次级样式、数据库位置「复制路径」、
  导航摘要单行省略。
- 修复：分隔线不再继承 muted（新增主题自适应 `--control-border`，亮 3.4:1 / 暗 4.2:1）；
  默认窗口尺寸工具栏按钮换行；主题数字输入 `step=any`（Print 默认 16.5px/375px 触发
  stepMismatch）；标签增删不再移动正文锚点；MCP 配置框空态说明与空内容禁用复制。
