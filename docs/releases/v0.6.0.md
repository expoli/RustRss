## 本版内容（每日日报）

- **每日日报**：按本地日历日（含 DST 偏移）聚合订阅内容，AI 生成结构化日报（总览 +
  分节要点）。侧栏「日报」分组：今日、昨日入口 + 最近历史日期行；历史报告带
  「历史报告」徽章可随时回看。设计定稿与阶段切分见
  [design](../../.chorus/specs/rss-reader/2026-10-03-daily-digest/design.md)。
  - 范围过滤：按源标签（feed_tags，OR 匹配）限定素材；未选标签覆盖全部订阅源。
  - 检查点对比：素材在生成后又有新增/变化/移出时，状态行给出分类计数并可一键更新。
  - 强制重写：复用已生成的文章要点重新组织内容，不重复消耗请求。
  - 缓存：文章要点（输入指纹）与分节/最终合成（内容寻址节点键，含端点身份与提示词
    版本）双层缓存，重复生成只对变化部分付费。
- **MCP 只读日报工具**：`digest_list`（元数据 + ≤140 字概览，默认 10、上限 50）与
  `digest_get`（成品 Markdown 32KiB 硬顶显式截断 + 来源清单分页），只读、绝不触发
  AI 生成；响应口径与既有 MCP 约定一致，缺报告返回机器可读错误。

## 工程质量（同主线提交，四轮独立评审）

- 提交 CAS：`digest_candidate_pairs` 单一查询源（窗口/范围/排序同源），提交事务内
  重解析 feed_tags；成员新增/版本递增/重打标签三类漂移测试钉死（`digest_schema.rs`
  `commit_cas_rejects_when_material_drifts`）。
- 单飞与取消：稳定槽位键（日期+范围+配置）原子抢占；job_id 含素材指纹供事件/取消
  身份；取消按 job_id 锁内反查注册表条目；崩溃残留的在飞标记可被接管；注册表生命周期
  单测（`digest_jobs_tests`）。
- 性能口径：侧栏/列表只读 `digests.summary`（≤140，CHECK 兜底），不 JOIN 正文大列；
  状态检查走 `digest_entry_meta` 覆盖索引（EXPLAIN 变异校验）；侧栏历史行 keyed
  reconcile 行级 patch。
- 打开路径互斥：`openDigestDate` 与文章阅读共用清选中 + 阅读令牌校验
  （`digest-open.test.cjs` 两场景回归）。
