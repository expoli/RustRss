## 本版内容

- Android 设置→数据新增「诊断日志」：列出沙盒 `logs/rustrss-*.log`（名称/大小/修改时间/
  当前标记），查看末尾 256KB（截断上限由后端响应直出），经系统文档选择器导出完整文件
  （16MB 软上限）——release 包无需 adb/root 即可取证排障。
- 只读日志 API 带文件名白名单守卫（防路径穿越）；末尾窗口切割点恰在行边界时保留完整首行；
  日志脱敏沿用写入口径，导出原样。
- 入口仅 Android 显示；桌面行为不变。
