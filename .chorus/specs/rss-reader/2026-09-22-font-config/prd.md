# PRD: 自定义字体配置

- 模块: rss-reader / font-config
- 日期: 2026-09-22
- 来源: Chorus Idea e930458d（用户需求 + Folo/Fluent Reader 对标）

## 问题

应用目前使用硬编码字体栈（body 一套、代码块一套），用户无法按偏好调整。中文用户可能想换思源黑体/霞鹜文楷等，英文用户可能想换 Inter/Segoe UI Variable 等。

## 需求（已 elaboration 确认）

| # | 需求 | 决策 |
|---|------|------|
| R1 | 字体来源 | 枚举系统已安装字体族（fontconfig；跨平台：Windows DWrite / macOS CoreText / Linux fontconfig），不加载外部字体文件 |
| R2 | 配置粒度 | 三类独立：UI 字体（全局控件）、正文字体（阅读区 article 区）、等宽字体（代码块） |
| R3 | 字号 | 正文字号可调（13-18px，默认 14px）；行高联动（1.5-1.8，默认 1.55） |
| R4 | 生效 | CSS 变量驱动，保存即生效，无需重启 |
| R5 | 设置 UI | 设置→外观页新增「字体」分区：三个自绘下拉（复用 SETTING_DROPDOWNS 基建）+ 字号滑块 |

## 验收标准

1. 设置页「外观」能看到系统字体列表（下拉，含「跟随系统」默认项）；选任一字体立即生效。
2. 三类字体独立：改 UI 字体不影响代码块，改正文字体不影响侧栏，改等宽字体只影响代码块。
3. 字号滑块拖动实时预览正文效果；行高随字号自动调整。
4. 重启后设置保留；i18n 双语 key。
5. core 无新依赖；`cargo test --workspace` 全绿。
