# 完整主题、设置组织与 MCP 视觉闭环

日期：2026-09-23。状态：设计草案，产品尚未实现。
Chorus idea：`6876476a-10ab-44c5-b12c-9e82a509fa40`。

## 已确认的目标

用户确认主题覆盖配色、字体、列表和阅读区风格；支持 agent 通过 MCP 调整，并取得真实渲染图片形成反馈闭环。用户已同意先整理设计、拆分任务、验证 WebView 截图能力。此前计数/视图 scope 修复为独立批次，不混入本特性的验收。

用户场景：“暖白纸张、橙色点缀、紧凑列表、衬线正文 18px；看看效果，再把阅读区调窄一些”。普通用户通过设置页完成相同操作，不要求使用 agent。

## 首版范围

- 三套完整预设：清爽、纸页、石墨，各有浅/深色配色；跟随系统或指定模式。
- 语义颜色、界面/正文/代码字体、字号、行距、内容宽度、段落间距、列表密度/摘要行数/缩略图、圆角与栏宽。
- 内置预设 + 用户覆盖项；局部修改不覆盖其它偏好；切换预设默认保留用户覆盖，提供明确的“使用整套预设”操作清空覆盖。
- UI 与 MCP 共用参数定义、校验、持久化、版本冲突处理和恢复能力。
- 运行中的桌面应用提供固定示例预览，MCP 返回 PNG + 结构化元数据；agent 可循环调整，最终保存或取消。
- 预览使用独立窗口与临时配置，正式阅读窗口在保存成功后更新；取消、超时或应用退出不改变持久化主题。
- 设置页重组与列表/阅读操作归位；中英双语、键盘可达、可恢复默认。

### 后续范围

任意 CSS/脚本/HTML 模板、主题市场、主题文件分享、应用关闭时自动启动渲染器、当前阅读窗口截图不进入首版。固定示例预览不加载真实订阅、文章、外部图片、凭据或任意 URL。

## 界面组织

| 位置 | 内容 |
| --- | --- |
| 外观与主题 | 主题卡片、浅/深色选择、界面字体、密度、栏宽、预览与恢复 |
| 阅读 | 正文字体/行距/宽度、文章显示、链接与已读行为、阅读布局 |
| 订阅与更新 | 订阅管理、刷新计划、通知、RSSHub |
| AI 助手 | 服务商/模型/密钥、摘要/翻译、发送与缓存 |
| 外部集成 | MCP 状态、客户端配置、写入权限 |
| 数据与备份 | OPML、备份恢复、存储位置 |
| 通用 | 语言、窗口/托盘、快捷键、诊断与关于 |

列表工具栏放筛选/排序/当前视图全部标读；阅读工具栏 Aa 面板放正文排版，星标/稍后读/AI 紧邻正文。Aa 与设置页使用同一配置字段。主题只修改视觉，不改变筛选语义或“全部标读”的 scope。

## 验收标准（产品尚未完成）

- [ ] 三套预设 × 明暗两种模式，侧栏、列表、阅读区、设置、弹窗、代码/diff、焦点/禁用/错误状态均有对应变量；硬编码颜色有明确例外清单。
- [ ] 旧模式/字体配置升级后仍有效；未知 schema 版本拒绝覆盖；无关设置和文章数据不变。
- [ ] UI 与 MCP 相同 patch 得到相同 effective config；同值修改不增加 revision、不写 DOM。
- [ ] 预览期间持久化配置不变；保存原子化；取消/超时/退出不覆盖用户期间产生的新设置。
- [ ] 每张图带 preview_id、preview_revision、config_hash、scene、mode、logical_size、pixel_size、scale_factor；不返回旧 revision 的图作为新结果。
- [ ] 三个固定场景（总览、文章、设置）共用生产组件/CSS，包含中英文、长标题、空/错误状态、引用、代码、diff、表格和离线图片。
- [ ] 读 token 看不到临时修改/保存/取消/截图工具；写 token 失效或写开关关闭后不能保存，也不能继续预览操作；本地取消始终可用。
- [ ] 应用关闭、渲染超时、预览过期、版本冲突、截图不可用有明确错误；参数读取/校验/配置保存可独立于渲染能力使用。
- [ ] 主题保存后主窗口不重建整列 DOM，当前文章/选择/焦点/阅读滚动锚点保留；排版变化时以段落锚点恢复，不能仅承诺固定 scrollTop。
- [ ] Windows、macOS、Linux X11/Wayland 分别验证；不可用环境保持未勾选，不以单平台推断全平台达标。
