# PRD: 订阅源编辑对话框

- 模块: rss-reader / feed-edit
- 日期: 2026-09-22
- 来源: Chorus Idea becbe9d0（用户需求 + Fluent Reader/QuickRSS 对标）

## 问题

订阅源右键菜单没有编辑入口：标题改不了（只能显示源站原始名）、文件夹/刷新间隔散落在子菜单、URL 不可见（想核对地址得去数据库找）。

## 已定决策（elaboration 确认）

| # | 决策 |
|---|------|
| D1 | **V1 不支持改 URL**：stable_id 按内容算，换地址重抓后旧条目已读/星标无法稳定继承，风险高收益低 |
| D2 | **单对话框收拢**：右键「编辑」打开对话框（标题/文件夹/刷新间隔 + URL 只读展示），保存即生效；右键快捷子菜单保留 |

## 需求

1. 右键菜单新增「编辑」项（立即刷新之后、移入文件夹之前）
2. 对话框字段：
   - 标题：文本输入，placeholder 显示源站名；空 = 清除自定义、回退源站名
   - 文件夹：自绘下拉（未分组 + 全部文件夹）
   - 刷新间隔：自绘下拉（跟随全局 + 5 档，同右键菜单）
   - 订阅地址：只读展示（可选中复制）
3. 自定义标题**不被刷新覆盖**（feed 元数据更新只动非用户字段）
4. i18n 双语；侧栏/列表/阅读区元数据同步更新

## 验收标准

1. 改标题 → 侧栏 feed 名、列表 feed_title、阅读区 meta 立即更新；刷新全部后自定义名保留
2. 对话框改文件夹/间隔 → 与右键菜单改等效（同一落库路径）
3. URL 只读不可改；取消关闭不改任何东西
4. cargo test --workspace 全绿；README/spec.md 同步
