# PRD: 右键菜单子菜单化（刷新间隔 / 移动到）

## 背景

订阅源右键菜单当前把「刷新间隔」6 个档位与「移动到: <文件夹>」（用户有 21 个分组）**平铺**在同一个菜单里，菜单非常长：滚动找项耗时、易误点，且破坏菜单的层级语义。改为**悬浮向右展开的子菜单**后，菜单本体只保留一层条目，交互接近原生菜单。

细化阶段已确认的 3 个决策：两处都改（刷新间隔 + 移动到）；悬停即展开且点击父项也可展开/收起；父项显示当前值。

## 需求

### FR-1 子菜单机制（通用）

右键菜单组件（`ui/app.js` 的 `openContextMenu`）支持「父项 + 子菜单」条目类型：父项渲染为一行（右侧带展开指示符），鼠标悬停**即**在右侧展开子菜单，点击父项亦可展开/收起；子菜单复用既有条目类型（普通项 / 勾选项 / 分组标题 / 分隔线）。

### FR-2 订阅菜单两处接入

- **刷新间隔**：父项文案显示当前档位（如「刷新间隔 · 跟随全局（每 30 分钟）」），子菜单内 6 个档位、当前档位打勾；
- **移动到**：父项文案显示当前分组（如「移动到 · 未分组」），子菜单内列出全部分组 + 「未分组」项，当前所在分组打勾。

### FR-3 视口安全

子菜单**不得溢出视口**：右侧空间不足时翻转到父项左侧；垂直方向超出时钳位或内部滚动（与既有 `placeMenu` 的「贴锚点 + 翻转 + 永不为负」口径一致）。子菜单贴父项行的实时位置（父菜单自身可滚动）。

### FR-4 关闭与切换语义

Esc 关闭整棵菜单树；点击外部关闭；点击子项执行动作并关闭；鼠标从子菜单移出到另一父项时切换子菜单；父菜单滚动时子菜单跟随或收起（不得错位）。

## 非功能要求

- UI 仍为原生 JS、无构建链；新增文案必须同时补 `ui/i18n.js` 的 zh-CN 与 en（key-set 测试守护）；
- 其余菜单（文件夹菜单、列表区菜单、设置页下拉）行为与外观不回归；
- 既有键盘口径（Esc 关闭）与「点击外部关闭」不回归。

## 验收口径（行为级）

1. 订阅菜单展开后：本体只含一层条目（刷新间隔/移动到各占一行），高度显著小于改造前（给出对照证据）；
2. 悬停父项 → 子菜单在右侧展开且当前档位/当前分组已打勾；点击父项同样展开/收起；
3. 视口右边缘附近右键 → 子菜单翻转到左侧且不出界；底部附近 → 垂直钳位/滚动，不溢出；
4. 点击子菜单项后动作生效（如切到「每 15 分钟」→ 菜单里父项文案与子项勾选同步更新、库值持久化）；Esc / 点击外部可关闭整棵树；
5. 其余菜单与新子菜单机制互不影响（无回归）。

## 范围外

- 菜单视觉大改版（配色/尺寸体系不变，仅新增展开指示符与子菜单容器）；
- 触屏长按菜单、菜单搜索/过滤；
- 文件夹菜单与设置下拉的改造（它们不长）。
