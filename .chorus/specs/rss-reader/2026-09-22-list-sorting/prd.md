# PRD: 文章列表排序与过滤

- 模块: rss-reader / list-sorting
- 日期: 2026-09-22
- 来源: Chorus Idea 03208f75（用户需求 + Fluent Reader/NetNewsWire 对标）

## 问题

列表固定「最新在前」：想从旧到新按序读不行；单源/全部视图里已读未读混排，想专注未读只能去「全部未读」视图（丢失源上下文）。

## 已定决策（elaboration 确认）

| # | 决策 |
|---|------|
| D1 | 三档排序：最新在前（默认）/ 最早在前 / 未读优先；另加**隐藏已读**开关 |
| D2 | **全局统一记忆**（存库），所有视图共用 |
| D3 | 入口：**列表头排序下拉**（图标按钮 → ctx-menu：三档 + 分隔 + 隐藏已读开关），复用现有菜单基建 |

## 需求

1. 列表头（标题/计数行右侧）加排序图标按钮，点击弹菜单：
   - ○ 最新在前 / ○ 最早在前 / ○ 未读优先（当前档打勾）
   - ───
   - ☑ 隐藏已读
2. 切换立即重查重渲（reset 语义，分页状态重置）
3. **所有视图生效**（未读 / 星标 / 稍后读 / 全部 / 单源 / 搜索——**无「搜索除外」**）：排序档对所有列表视图生效；「隐藏已读」唯一豁免是**星标 / 稍后读视图**（读完了的星标还得能找回），搜索同样过滤；「全部未读」视图里隐藏已读开关冗余但无害
4. 未读优先 = `ORDER BY read ASC, 时间 DESC`（未读群里仍最新在前）
5. keyset 分页游标按排序档适配（最早在前 = 方向反转；未读优先 = 复合键游标 `(read, sortkey, id)`）
6. i18n 双语；README/spec.md 同步

## 验收标准

1. 三档切换后列表顺序正确且切回视图/重启保留
2. 最早在前：无限滚动续页正确（更旧的接着来，不重复）
3. 未读优先：未读全在前（组内时间倒序）、已读组在后；续页正确
4. 隐藏已读：开启后已读行立即从列表消失；灰显防删行逻辑（点击标读）与之共存（灰显行在下次重建时离开）；星标/稍后读视图豁免
5. 后台刷新：只有「最新在前」档走 prepend（插头部 + 滚动位置补偿）；最早在前 / 未读优先档退化为静默 reset——新条目分别属于列表尾部 / 未读组头部，插头部会让 DOM 顺序与后端顺序不一致
6. 性能：未读优先档首屏与续页都走迁移 v11 的表达式索引、无临时排序；断言与线上 SQL 同源且经变异校验
7. cargo test --workspace 全绿
