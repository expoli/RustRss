# PRD: 新文章通知 + 托盘未读角标

- 模块: rss-reader / notifications
- 日期: 2026-09-21
- 来源: Chorus Idea 347916f1（对标差距分析 P0-2；依赖 P0-1 自动刷新已交付）

## 需求（已 elaboration 确认）

| # | 需求 | 决策 |
|---|------|------|
| R1 | 通知形式 | 聚合单条系统通知「N 篇新文章」，点击聚焦主窗口；可全局开关 |
| R2 | 触发 | 默认关，设置页开；仅后台定时/启动刷新触发（手动刷新不通知——用户已在看） |
| R3 | 托盘角标 | 未读数变化时更新托盘角标（数字优先；平台能力不足退化为圆点或窗口标题计数）；托盘不可用沿用现有静默降级 |
| R4 | 驱动层 | Rust 侧 scheduler 驱动：刷新前后比对未读数差值，差值>0 且开关开 → 通知；未读数变化 → 角标（不依赖前端存活） |

## 验收标准

1. 开启通知后，后台定时刷新带来 N>0 篇新增未读时弹出一条聚合通知；点击通知聚焦/唤出主窗口；手动刷新不产生通知。
2. 托盘角标随未读数变化更新；读完全部后角标清空；托盘不可用环境无崩溃、无错误日志刷屏（沿用降级模式）。
3. 设置页新增「新文章通知」开关（默认关），zh-CN/en 双语 key；读写进 settings 表（归一化沿用现有模式）。
4. 通知触发逻辑的纯函数部分（差值计算/开关判定）带单元测试；`cargo test --workspace` 全绿；README 同步。
