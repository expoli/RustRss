# PRD: RustRss README 与文档整理

## Background

README 已积累了大量实现细节、用户操作说明和阶段验收记录，难以快速理解产品，也不适合作为项目宣传入口。README 中部分早期架构描述和“进行中”状态与当前实现不一致。项目还没有可展示真实产品界面的截图或分层的用户文档。

## Requirements

### Functional Requirements

- FR-1: README 成为面向新访客的中文项目首页，简洁说明产品定位、主要能力、试用/安装状态、隐私要点和文档入口。
- FR-2: README 包含由当前桌面应用生成的产品截图；截图使用隔离的演示数据库，不包含用户私有订阅或凭据。
- FR-3: 把仍适用的用户说明和开发说明按主题组织在 `docs/`，并从 README 与相应指南互相导航。
- FR-4: 删除或改写 README 中过时、重复、过细或不准确的内容；仍有价值的实操说明迁移到匹配的指南。
- FR-5: 需求基线、阶段分析和手工验收证据继续存于 `.chorus/specs/`，不把验收记录搬进宣传页。

### Acceptance Criteria

- README 首页只保留项目介绍、真实产品截图、安装/试用说明、隐私要点和文档导航。
- 新文档覆盖快速上手、功能概览、内置 AI、MCP 使用及开发/发布入口；读者能从 README 到达这些说明。
- README 与新文档中的相对文件链接和截图路径都有效。
- 文案不宣称尚未发布的平台安装包可下载，不把未完成或未验证能力写成已完成。
- 至少两张应用截图由隔离演示数据的真实桌面应用运行时生成。
- `.chorus/specs/rss-reader/spec.md` 中新增的文档验收点已勾选；已有手工验收记录未改写。

## Out of Scope

- 不新增应用功能或重设计界面；仅修复截图过程中发现的启动提示遮挡正常界面问题。
- 不创建网站、发布仓库或制作新的品牌插画。
- 不搬迁或重写 `.chorus/specs/` 中的需求和验收归档。
