# PRD: 自动刷新三件套（定时刷新 + 启动刷新 + OPML 导入后自动抓取）

- 模块: rss-reader / auto-refresh
- 日期: 2026-09-21
- 来源: Chorus Idea e565432a（对标 QuickRSS/Folo 差距分析 P0-1）

## 问题

1. 全仓库无定时刷新调度——刷新只有手动（按钮/`r` 键全量、右键单源、新增源后一次）。
2. 启动只 `loadAll()` 读库，打开应用看到的是上次关窗时的旧数据。
3. OPML 导入只写 feeds 表即返回（`src-tauri/src/commands.rs:629` → `ui/app.js:1540` loadAll），导入源全部 0 条目，必须手动再点一次刷新——UX 断层。

## 需求（已 elaboration 确认）

| # | 需求 | 决策 |
|---|------|------|
| R1 | 全局定时刷新 | 默认 30 分钟；档位 关/15m/30m/1h/2h/6h；存 settings 表，默认值单点定义 |
| R2 | 启动时自动刷新 | 默认开，可关；延迟 10s 等首屏数据落定 |
| R3 | OPML 导入后自动抓取 | 导入完成 → 后台抓取新导入源（复用现有 refresh 管线）→ 完成后侧栏计数自动出现 |
| R4 | 并发策略 | 单 flight：共享原子进行中标记，进行中则本次 tick 跳过 |
| R5 | UI 反馈 | 复用现有 setStatus 文案模式，不打断阅读焦点 |

## 非目标

- 每源独立刷新间隔（后续可加，本版全局一档）
- 刷新完成系统通知（P0-2 范畴）

## 验收标准

1. 设置页新增「自动刷新间隔」选择（6 档含关闭）与「启动时刷新」开关，zh-CN/en 双语 key 齐全（key-set 测试通过）。
2. 间隔设为非关闭时，到点自动执行 refresh_all（等价手动刷新路径，含状态栏提示）；进行中再到点跳过。
3. 启动 10s 后自动触发一次刷新（可关）。
4. OPML 导入 N 个新源后自动后台抓取这些源，完成后 `loadAll()` 侧栏计数非零（网络可达时）。
5. core 层设置项读写带测试；`cargo test --workspace` 全绿。
